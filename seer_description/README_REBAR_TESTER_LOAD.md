# 钢筋自动装填拉伸测试机（Isaac Sim + MoveIt 2）

`test_rebar_tester_load.py` 实现完整流程：**机械臂抓取钢筋 → 底盘开到拉伸测试机
→ 钢筋竖直送入上下抱爪 → 闭合抱爪 → 确认测试机持有钢筋 → 松爪撤回**。
配套 `rebar_tester_gui_qt.py` 提供测试机手动控制面板。

## 前置条件

- 实验室场景（含测试机桥接）：

```bash
source /opt/ros/lyrical/setup.bash
source install/setup.bash
ros2 run seer_description start_warehouse_finger_rebar_lab_demo.sh --gui --no-rviz --domain-id 133
```

- MoveIt 规划场景：脚本自动把测试机柜体、双立柱、顶梁、下台板与控制台
  以 world 系碰撞盒加入 `/apply_planning_scene`（运动横梁不入场景——全行程
  包络会挡住插入路径；横梁位置由脚本按指令状态控制）。

## 装填几何（实测推算，见 `rebar_tester_geometry.py`）

| 项 | 值 |
|---|---|
| 夹持线（世界系） | x = 6.00, y = 3.92 |
| 钢筋（0.6 m）插入中心 | (6.00, 3.92, **1.50**)，底端 1.20 / 顶端 1.80 |
| 送入方式 | 南侧（−Y）水平送入，钢筋中心终点 y = 3.90 |
| 下爪夹持 | 升至 **1.12**（尖端跨 1.1775–1.2125 夹底端） |
| 上爪夹持 | 降至 **1.87**（尖端跨 1.7775–1.8125 夹顶端） |
| 双爪闭合开口 | **0.024 m**（= 钢筋直径；0.16 开口时横向容差 ±6.8 cm） |
| 底盘停靠位 | (6.0, 3.05), yaw −90°（朝南、机械臂朝北） |
| 运输姿态 | 钢筋抬至 z ≈ 1.2 收近身（护栏 0.9 m、工作台 0.81 m 均可越过） |

> 0.6 m 是实验室场景取料工位钢筋的实际长度。测试机上下爪最大夹持跨度
> 0.845 m，**1 m 钢筋物理放不进**；如需更长试样需同时修改场景与爪位参数。

## 运行

```bash
export ROS_DOMAIN_ID=133

# 完整自动流程（JSON 报告 + 退出码）
ros2 run seer_description test_rebar_tester_load.py --output /tmp/load.json

# 仅规划/可达性核对（不驾驶、不执行）
ros2 run seer_description test_rebar_tester_load.py --plan-only

# 手动闭合抱爪模式：装填到位后暂停，用 GUI 手动夹紧再回车继续
ros2 run seer_description test_rebar_tester_load.py --manual-jaws
```

流程与判定：

| 阶段 | 判定 |
|---|---|
| 测试机预置（上 1.88 / 下 1.05 / 双开 0.16） | `_state` 到位 ±5 mm |
| 抓取（同 `test_rebar_grasp.py` 逻辑） | 手指接触停滞 + 提起保持 |
| 高位运输三段移动 | 每段钢筋相对夹爪偏移 < 5 cm |
| 闭环驾驶 (0,0)→(4.5,0)→(4.5,2.6)→(6,2.6)→(6,3.05) | 里程计到位 ±2 cm / ±0.02 rad；臂作业时保持停靠位 |
| 竖直化（24 步慢速插值） | 钢筋轴向 |Z| > 0.95 |
| 送入夹持线 | 笛卡尔执行成功 + 负载监控（终点内缩 2 cm） |
| 抱爪闭合 | 下 1.12 / 上 1.87 / 开口 0.024，`_state` 确认 |
| 测试机接管钢筋 | `/rebar_tester/rebar_gripped` 为 `true`；收到反馈后机械臂才松爪 |
| 松爪保持 | 钢筋 TF 仍在夹持线 x±3 cm、y±5 cm、z±8 cm |
| 撤回收臂 | 笛卡尔退回 + 关节收臂 |

### 仿真抓取约束

机械臂先靠双指与钢筋的真实碰撞完成抓取，并通过夹爪停滞及抬升后的钢筋位姿
确认持有。随后流程发布 `/rebar_tester/robot_attach_cmd`（`std_msgs/Bool`
`true`）；Isaac 在当前钢筋位姿创建夹爪电机到钢筋的临时固定关节，
`/rebar_tester/robot_attached` 返回 `true` 后才继续搬运。附着期间钢筋碰撞关闭，
避免固定关节与双指的接触约束互相冲突；MoveIt 仍将钢筋作为附着碰撞体规划。
测试机双爪闭合且钢筋实测位置、方向达标时，Isaac 移除临时关节、恢复碰撞，
并将钢筋保持在当前位置。`/rebar_tester/rebar_gripped` 为 `true` 且
`robot_attached` 为 `false` 后，机械臂才能松爪。

新一轮仿真启动时自动丢弃旧的附着命令，防止上次中断的 `true` 误附着未抓取的钢筋。
若起始钢筋偏离取料位超过 3 cm，流程立即停止。

### 实测踩坑记录（对后续调参有用）

- **停靠位**：(6.0, 2.9) 时插入点 IK 不可达；3.0 仍临界；**3.05 可靠**。
  夹持线正上方那一点从 3.05 也不可达（探针 20/21 点可解，仅 y 偏移 0 失败），
  因此插入终点内缩 2 cm（仍在爪尖 y±5 cm 夹持跨度内）。
- **行驶路线**：直行 (0,0)→(6,0) 会撞工作台桌腿（x 5.99–6.11）；绕行
  (4.5,0)→(4.5,2.6)→(6.0,2.6)；最后 180° 转向必须在 y≤2.6 完成（对角扫掠
  0.61 m，柜角在 y 3.59），末段 0.45 m 用倒车（drive_to 支持近距倒车分支）。
- **臂展临界**：工位上方直抬 1.2 m 半径 1.04 不可达；先侧移脱离鞍座再走
  0.90 高度（onboard 验证值）；绕机身两段对角在 closing-Y 朝向下 IK 临界，
  改单段直达。
- **竖直化甩脱**：12 步 0.15 scaling 会把钢筋甩出（V 形边缘夹持）；改 24 步
  0.06 scaling 后未再发生。竖直化点需偏离臂平面（y 0.35）且高度 1.10
  （wrist-down 到达 0.82 / 转正后 0.62，均远离 0.90 临界）。
- **插入走廊 IK 分支**：y≈grip−0.20 处笛卡尔连续求解因关节分支切换中断
  （单点 IK 有解）；该段自动回退**关节空间规划**（`joint_fallback`）打通。
- **钢筋装填高度**：bar 中心必须 ≈1.50（下爪尖 1.19 / 上爪尖 1.79 恰好覆盖
  0.6 m bar 两端）。当前物理抓取在钢筋中心，故 TCP 高度也取 1.50；
  从 y=3.05 停靠位的 IK 探针已验证该位置可达。
- **偶发夹持脱落**：约 2/10 轮次在搬运/竖直化中松脱（V 形夹持物理随机性），
  重跑即恢复；如需根治需改手指接触面几何（在 aubo_ros2_driver 子模块，未动）。

## 手动控制 GUI

```bash
ros2 run seer_description rebar_tester_gui_qt.py
```

- 四行控制：上/下横梁高度（1.50–1.88 / 0.92–1.34）、上/下爪开口（0.024–0.16），
  滑杆 + 输入框 + 发送按钮，实时回显四个 `_state`
- 快捷键：**预置装填位**（上 1.88 下 1.05 全开）、**双爪全开**、**双爪夹紧**
- 越界输入拦截并提示；状态超时显示断线警告
- 依赖 PySide6；也可运行 tkinter 版 `rebar_tester_gui.py`

## 已知限制

- 抱爪为运动学模型，无夹持力/拉断仿真。Isaac 仅在钢筋位姿、姿态和双爪状态
  均满足装填条件时把钢筋刚体切换为运动学保持，并通过
  `/rebar_tester/rebar_gripped` 报告；张开任一抱爪会解除保持。此接管功能仍待联机验证。
- 底盘驾驶基于里程计闭环；PhysX 无滑移，残余误差由 6.8 cm 爪口容差吸收
- 完整流程执行后钢筋留在测试机内；重复运行前需重启场景复位钢筋
