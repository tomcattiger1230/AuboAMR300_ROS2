# 腕部 ArUco：测试机夹具相对定位研究（2026-11-06）

用户已确认使用机械臂腕部相机，测量标记相对测试机夹具的位姿。本轮实现了独立离线原型和几何验证，没有连接相机/机器人、修改导航地图、启动仿真或训练，也没有加载策略或 optimizer。现场标记、内参、手眼与同步数据尚未提供，因此这不是实机接入或精度验收完成。

## 对工程流程的改变

现有导航负责到达测试机附近可安全观察的位置；新增模块在每次钢筋传递前重新测量“夹具相对机器人”的位姿。局部上料目标由当前视觉测量变换到控制基座，不再仅依赖地图停靠点的绝对位置。标记还绑定唯一测试机 ID，三台同型设备不能只靠相似外观区分。

建议的候选流程：

1. 导航到经过碰撞/可达性检查的观察位，确认底盘真实停止、托槽承载和钢筋运输守卫成立。
2. 用经过验证的安全路径将腕部相机移到观察位，获取原分辨率图像及曝光时刻的机械臂 FK。
3. 识别指定机器的标记，检查标记边长、候选位姿歧义、重投影误差和至少三个不同时间的稳定观测。
4. 若停靠误差较大，先安全收臂、重新核对载荷/运输守卫，再通过单独的精停靠接口做底盘小范围调整；本模块只提供几何误差，不发轮速。
5. 任何底盘移动之后废弃原会话，重新取图和校正。确认夹具相对位姿、设备身份、空闲/就绪、原钢筋视觉与力传感条件后，才进入现有传递技能。
6. 腕部离开观察位仍须走验证过的返回路径；上料前继续刷新相关视觉证据，不复用过期图像。

标记固定在测试机本体，或者刚性连接且不会相对夹具移动的支架上。仅放在“附近”的独立物体上，可能只能校正到该物体，无法保证夹具仍在原处。标记不能随活动夹爪、护罩或振动支架移动。每台机器使用不同 ID，安装后保留测量版本；设备搬迁、夹具更换或标记移动都要复测关系。

## 坐标链与标定要求

约定 `A_T_B` 把 B 系列向量变换到 A 系，单位 m；B=控制基座，E=机械臂法兰，C=相机 optical，M=标记，F=夹具。F 的原点是当前技能的夹具目标点，轴方向与工位模板一致；现场使用其他夹具测量坐标系时必须显式转换，不能只拿三个 XYZ 数值代替完整位姿。

```text
B_T_F = B_T_E(exposure) × E_T_C(hand-eye) × C_T_M(PnP) × inverse(F_T_M(survey))
F_T_B = inverse(B_T_F)
P_base = B_T_F × P_fixture
```

`B_T_E` 必须使用相机曝光时刻的反馈/FK；手眼标定 `E_T_C` 必须明确是 flange→optical，不能混作 TCP→相机或 OpenGL 相机轴。若机械臂 FK 的 base 与底盘控制 base 不同，还需经过测量的固定变换，先组成正确的 `B_T_E`。代码同时绑定 base/flange/optical frame ID 和共同 clock ID，标定版本不匹配即拒收。

PnP 使用匹配相机序列号、镜头设置和原图尺寸的 K/畸变。OpenCV 返回的是标记到相机的变换；IPPE_SQUARE 需要规定顺序的四个角点，并可能有多个候选。原型保留所有有效候选，检查正深度和正面可见性；如果候选误差相近但位姿差异显著，直接要求其他视角或多标记板，不默默选一个。[OpenCV PnP 文档](https://docs.opencv.org/4.x/d5/d1f/calib3d_solvePnP.html)

若将来需要校正导航地图中的机器人位姿，还需独立测量 `map_T_F`：`map_T_B = map_T_F × inverse(B_T_F)`。本轮用户提供的范围是夹具相对标记关系，足以研究局部对接；不能据此宣称地图绝对定位也已校准。本轮不调用 SEER 重定位/地图重置接口。

仓库已有 `seer_description/scripts/calibrate_camera_intrinsics.py` 和 ChArUco 采集工具，可产生相机内参，但内参不等于手眼标定。手眼还需要多个具有充分旋转变化的机械臂姿态、对应标定板图像，以及独立留出姿态验证。[OpenCV 手眼标定](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)

## 标记与精度

`config/machine_fiducials_offline.json` 暂用 DICT_5X5_100，机器 1/2/3 的 ID 为 11/12/13，建议初步试装 160mm 外黑框边长；全部是未测量的研究提案，不是现场配置。最终尺寸要按实际观察距离、视场、遮挡、清晰度和曝光验证。打印后量实际外黑框边长，保留白色外边距、使用平整哑光刚性底板，不把纸张总宽度或内部小方格尺寸当作标记尺寸。[OpenCV ArUco 检测](https://docs.opencv.org/4.x/d5/dae/tutorial_aruco_detection.html)

不能先承诺 ArUco 单独保证 3mm。误差预算至少包括：标记尺寸/安装测量、镜头畸变、角点噪声、手眼、FK/机构误差、时间同步和结构挠曲。例如 0.5m 杠杆臂上 1° 方向误差约对应 8.7mm 横向误差；160mm 标记的 0.5mm 尺寸误差，在约 0.8m 距离上产生约 2.5mm 的一阶尺度误差。多帧稳定只能反映重复性，不能证明没有系统偏差。

初步验收应覆盖三台设备、不同到站偏差/距离/角度/光照、遮挡、底盘静止但腕部移动，以及故意错 ID、过期图、镜头/手眼版本改变。用独立量具测夹具目标误差和角度误差，报告最大值、分位数与拒收率；原夹紧、松爪、承载、钢筋速度、退让和接触门槛继续独立保留。标记观测本身不证明钢筋已被正确夹持。

## 本轮代码与验证范围

- `fiducial_localization.py`：实际 ArUco 检测、IPPE 双候选、完整 SE(3) 坐标链、同曝光 FK/版本/时钟检查、稳定会话与局部停靠误差。返回的 `loading_authorized` 始终为 false。异常使会话失效，必须使用新会话。
- `fixture_loading_geometry`：把夹具局部目标、预插入、轴向、姿态与退让变换到控制基座；三个平面工位与旧接口数学结果一致，但未据此声明冻结 PPO 在新感知分布上兼容。
- `fiducial_check.py`：180 项有噪声角点投影，以及三台机器 ID 的投影标记图检测。使用精确虚拟标定，仅作数学/检测代码检查，未运行物理仿真。这些数字不是毫米级实机成功率。

所有门限为候选值，尚未现场标定验收：图像/FK ≤200ms、曝光/FK 时间差 ≤5ms、单角点重投影 RMS ≤1px、可见边长 ≥60px、三帧相对位姿差 ≤3mm/0.5°，局部调整包络 ≤100mm/10°。8mm/0.5° 到站候选阈值是底盘停靠筛选，不替代钢筋末端原 3mm/3° 验收。

```sh
PYTHONPATH=rebar_training/src rebar_training/.venv/bin/python -m rebar_training.fiducial_check \
  --output /tmp/new_fiducial_projective_check
```

输出路径必须不存在。证据位于 `artifacts/aruco_fixture_relocalization_20261106/`。原 `MissionFlow`、实际导航服务和冻结仿真入口没有自动切换到该候选；本轮没有机器人动作。下一步的现场输入是原分辨率腕部图像、同步法兰反馈、内参/手眼及实测 `F_T_M`，先做只读真实数据回放，再单独开展受控实机接入。
